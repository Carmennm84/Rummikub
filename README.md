# Rummikub

Juego de Rummikub contra 1 a 3 computadoras, sin anuncios. Funciona en el navegador del móvil y se puede instalar como app.

## Publicarlo en GitHub Pages
1. En github.com crea un repositorio nuevo (por ejemplo `rummikub`), público.
2. Pulsa **Add file → Upload files** y sube **todos** estos archivos a la raíz: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png`.
3. Pulsa **Commit changes**.
4. Ve a **Settings → Pages**. En *Build and deployment* elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
5. Espera 1 o 2 minutos. Arriba aparecerá tu enlace: `https://TU-USUARIO.github.io/rummikub/`.

## Instalarlo en el iPhone
1. Abre ese enlace en **Safari**.
2. Pulsa **Compartir → Añadir a pantalla de inicio**.
3. Saldrá con el icono de las fichas 5-6-7. Una vez cargado, también funciona sin conexión.

## Compartirlo
Pasa el enlace de GitHub Pages. Cada persona lo instala igual y su marcador de victorias se guarda en su propio móvil.

## Actualizar
Sustituye `index.html` en el repositorio (Add file → Upload files). Si no ves el cambio, cierra y vuelve a abrir la app, o sube la versión en `sw.js` (`rummikub-v1` a `rummikub-v2`).
